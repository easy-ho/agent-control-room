# 에이전트 관제실 · Agent Control Room

A macOS app that watches your local Claude Code sessions like a CCTV control room.
로컬 Claude Code 세션을 CCTV 관제실처럼 보여 주는 macOS 앱입니다.

- 세션과 서브에이전트를 방에서 일하는 캐릭터로 보기 (Claude Code · Codex · Gemini CLI · Antigravity CLI)
- 권한 요청을 터미널 대신 앱에서 허용·거부
- 결재함: 목업을 보며 클릭으로 결정
- 앱에서 세션에 프롬프트·이미지 보내기
- 테마·캐릭터 팩 추가
- 앱 안 자동 업데이트

## 설치 · Install
1. [Releases](https://github.com/easy-ho/agent-control-room/releases/latest)에서 `AgentControlRoom-<버전>.zip`을 받아 풉니다.
2. `Agent Control Room.app`을 응용 프로그램(Applications) 폴더로 옮깁니다.
3. 처음 열 때 막히면: 시스템 설정 → 개인정보 보호 및 보안 → [그래도 열기] (공증되지 않은 앱).
4. 첫 화면에서 [켜기]를 누르면 권한·결재·지시 연결이 됩니다.

요구 사항: macOS 14+, Claude Code (Codex·Gemini·Antigravity CLI 는 선택).

이 저장소에는 릴리스(앱)만 있습니다. This repository hosts release builds only.
